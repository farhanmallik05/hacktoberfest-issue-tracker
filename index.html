Copilot Prompt Studio

Battle-tested prompts engineered for rapid open-source onboarding. Copy and paste directly into GitHub Copilot Chat in VS Code.

1. Architecture Onboarding

Rapid Codebase Exploration

Deconstruct unfamiliar repositories and identify key pipelines before touching code:

Explain the architecture of this repository. What is the entry point, how is state managed, and what are the main data flow pipelines? Give me a 3-bullet summary suitable for a new contributor.
2. Root Cause Analysis

Surgical Bug Diagnostics

Isolate root cause from issue tickets and produce minimal non-breaking diffs:

Here is the issue: [PASTE ISSUE BODY]. Looking at [FILE_PATH], diagnose why this error occurs and provide a minimal, non-breaking fix with validation steps.
3. Unit Test Generation

Arrange-Act-Assert Test Suite

Generate comprehensive test coverage including happy paths, errors, and boundary limits:

Generate a unit test suite for the function [FUNCTION_NAME] in [FILE_NAME]. Use pytest/jest conventions, mock external HTTP requests, and include assertions for happy path, 400 bad request, and 404 not found.
4. Pull Request Drafter

Maintainer-Ready PR Summaries

Transform git commits into structured, conventional PR descriptions ready to merge:

Summarize my recent git changes into a polished Pull Request description. Include: 1) What problem was solved, 2) Key changes made as bullet points, 3) How maintainers can verify the fix, and 4) Closes #[ISSUE_NUMBER].
